# MSOT-SCAN Digital Twin

Browser-based digital twin interface for multimodal concrete seepage forensics.

## Files

- `index.html` - GitHub Pages entry point
- `proj.html` - Local application entry point
- `styles.css` - Application styles
- `script.js` - Sensors, calculations, charts, presets, and report interactions

Open `index.html` or `proj.html` in a browser. For GitHub Pages, set the repository Pages source to the `main` branch and `/ (root)`.
